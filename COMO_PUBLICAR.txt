COMO COLOCAR O SITE NA INTERNET

ANTES DE PUBLICAR
1. Coloque suas imagens dentro da pasta "portfolio".
2. No Windows, abra ABRIR_SITE.bat uma vez.
3. Isso atualiza portfolio.js com a lista das suas artes.
4. Confira o site no computador e no celular.

IMPORTANTE
O arquivo ABRIR_SITE.bat é só para VOCÊ atualizar o portfólio no seu computador.
Quem visitar o site pela internet não precisa baixar ou executar nada.

OPÇÃO RECOMENDADA — GITHUB PAGES
1. Crie uma conta no GitHub.
2. Crie um repositório novo, por exemplo: felipedaltonico-site
3. Envie TODO o conteúdo desta pasta para o repositório:
   - index.html
   - style.css
   - script.js
   - portfolio.js
   - pasta portfolio
   - pasta colorir
   - .nojekyll
4. Nas configurações do repositório, abra a área "Pages".
5. Configure a publicação a partir da branch principal (main), pasta raiz (root).
6. Depois da publicação, você receberá um endereço parecido com:
   https://SEU-USUARIO.github.io/felipedaltonico-site/

PARA ATUALIZAR AS ARTES DEPOIS
1. Coloque/remova imagens na pasta portfolio no seu computador.
2. Execute ABRIR_SITE.bat novamente.
3. Envie ao GitHub as imagens alteradas e o novo portfolio.js.
4. O site público será atualizado após a nova publicação.

DOMÍNIO PRÓPRIO
Depois você pode comprar algo como:
felipedaltonico.com.br
e apontar esse domínio para o site hospedado.

OBSERVAÇÃO
Os nomes exatos dos menus das plataformas podem mudar, mas a estrutura do processo é:
subir os arquivos estáticos -> ativar Pages -> receber um link público.
