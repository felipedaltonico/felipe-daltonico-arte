COMO USAR ESTA VERSÃO

1) ABRIR O SITE
- Dê dois cliques em ABRIR_SITE.bat.

2) COLOCAR ARTES NO PORTFÓLIO
- Jogue PNG, JPG, JPEG, WEBP ou GIF dentro da pasta "portfolio".
- Depois abra novamente pelo ABRIR_SITE.bat.

3) TROCAR O DESENHO DE COLORIR DO TOPO
- Abra a pasta "colorir".
- Substitua o arquivo desenho.png pelo seu PNG transparente.
- IMPORTANTE: mantenha o nome exatamente como "desenho.png".
- Recomendo PNG com fundo transparente e apenas line art.

4) COMO DESENHAR NO SITE
- A caneta roxa é o cursor.
- Segure o BOTÃO DIREITO do mouse e arraste para desenhar.
- O traço nasce exatamente na ponta da caneta.
- Use o seletor de cor para mudar a tinta.
- Use a barra de tamanho para aumentar/diminuir o traço.
- Clique em "desenho ligado/desligado" para ativar ou desativar.
- Clique em "apagar desenho" para limpar tudo.

5) TABELA DE PREÇOS
CARTOON:
- 1 personagem sem cenário: R$ 60
- 2 personagens sem cenário: R$ 100
- Personagem adicional: + R$ 30

ANIME / OUTRO ESTILO:
- 1 personagem sem cenário: R$ 90
- 2 personagens sem cenário: R$ 130
- Personagem adicional: + R$ 40

Cenário: valor depende da complexidade.


V3 - NOVOS CONTROLES
--------------------
DESENHAR:
- Deixe "desenho ligado".
- SEGURE O BOTÃO DIREITO do mouse.
- Arraste a ponta da caneta pela página.
- Solte o botão direito para parar.
- O menu de contexto é bloqueado somente enquanto o desenho estiver ligado.
- Use "desenho desligado" para voltar a usar o botão direito normalmente.

PORTFÓLIO EM TELA CHEIA:
- Clique em qualquer arte do portfólio.
- Use as setas laterais ou as teclas ← e → para navegar.
- Aperte ESC, clique no X ou clique fora para fechar.


V4 - CORREÇÃO DO DESENHO
-------------------------
- O desenho agora usa CANVAS fixo na tela para ficar exatamente na ponta do mouse.
- Segure o BOTÃO DIREITO e arraste.
- O indicador muda para “desenhando…” enquanto o botão estiver pressionado.
- O menu do botão direito fica bloqueado apenas enquanto “desenho ligado” estiver ativo.
- O desenho não é mais ocultado em notebooks com tela touch/híbrida.


V5 - DESENHO REFEITO
--------------------
A ferramenta foi refeita usando um canvas do tamanho da página inteira.

TESTE:
1. Abra pelo ABRIR_SITE.bat.
2. Confirme que aparece "desenho ligado".
3. Coloque o mouse em uma área vazia da página.
4. SEGURE o botão DIREITO.
5. Sem soltar, arraste o mouse.
6. Enquanto o clique estiver sendo reconhecido, o painel mostra:
   "botão direito detectado ✓" ou "desenhando…"
7. Solte para parar.

O clique esquerdo NÃO desenha.
O botão "desenho desligado" devolve o clique direito ao funcionamento normal.


V6 - CANETA SEPARADA DO RESTO DO SITE
-------------------------------------
A ferramenta agora está no arquivo drawing.js.
Ela funciona independentemente de idiomas, portfólio e formulário.

COMO TESTAR:
1. Abra ABRIR_SITE.bat.
2. NÃO clique no botão se ele já mostrar "desenho ligado".
3. Vá para uma área vazia.
4. Pressione o botão DIREITO do mouse.
5. O status deve mudar para "botão direito ✓".
6. Continue segurando e arraste.
7. O status muda para "desenhando…".
8. Solte para parar.

IMPORTANTE:
- O desenho começa apenas com o botão direito.
- Depois que o botão direito é detectado, o site continua desenhando até o mouseup.
- O clique esquerdo não inicia desenho.
- O botão "desenho desligado" devolve o menu normal do botão direito.


V7 - TESTE VISUAL
-----------------
Assim que o site abrir, o painel deve mostrar:
CANETA PRONTA ✓

Isso confirma que o código da caneta carregou.

Para desenhar:
1. deixe "desenho ligado";
2. segure o botão DIREITO;
3. o painel muda para "botão direito detectado ✓";
4. arraste sem soltar;
5. o painel mostra "desenhando…";
6. solte para parar.

Nesta versão o canvas é fixo na tela e captura o ponteiro somente
depois que o botão direito é pressionado. Os cliques normais do site
continuam funcionando enquanto você não está desenhando.


V8 - AGORA O DESENHO FICA SÓ NA ARTE DO CANTO
---------------------------------------------
Mudança pedida:
- não desenha mais no site inteiro;
- desenha apenas em cima do desenho da folha no canto.

Como usar:
1. deixe "desenho ligado";
2. leve o mouse até a arte do canto superior;
3. segure o botão direito;
4. arraste para colorir apenas aquela arte;
5. solte para parar.

O clique direito fora da arte não desenha.


V9 - A IDEIA DE DESENHAR FOI REMOVIDA
-------------------------------------
Agora existe uma PALETA CRIATIVA.

O visitante pode:
- clicar em 5 cores prontas;
- escolher qualquer cor no seletor cromático;
- clicar em "surpreenda-me" para escolher uma paleta aleatória.

A cor escolhida muda:
- manchas e tinta atrás da arte;
- botões;
- fitas;
- rabiscos e textos de destaque;
- outros detalhes gráficos do site.

Não existe mais canvas nem desenho com o botão direito.
